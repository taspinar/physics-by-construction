- Issue: #335 (source: `docs/roadmap.md`, F96). Slots AI6 and AI7 of the
  physics reasoning path.
- Branch: `feature/335-multimodal-physics-reasoning-and`; base `fa0e51a`.

## Design

Two format 2 lessons in `agents-llm` with `course: mechanics`, methods
`simulation` and `llm-agents`.

| Dir | Id | Slot | Content |
|---|---|---|---|
| `16-multimodal-physics-reasoning` | `multimodal-physics-reasoning` | AI6 | Four still pictures, each a verified figure of the site drawn by its own lesson's `draw_` function: a conceptual force sketch (M2), a simulated velocity plot (M2), a simulated field image (EM1), a calibrated measurement (GW150914, M16). Ten questions: object properties (affordances), spatial relations, image-based counterfactual predictions; the build recomputes every answer from the physics code and scores the recorded answers |
| `17-interpretable-physics-explanations` | `interpretable-physics-explanations` | AI7 | One picture (the M2 velocity plot) and the scene's given values; for each question the model gives a prediction with an interval, a unit, and an explanation chosen from fixed candidate relations; the build tests the prediction and, separately, the explanation: unit, dimensional consistency (a scaling test), physical consistency against the verified result, consistency with the model's own prediction, and coverage of the interval |

- **Pictures are inputs, not committed files.** The harness gains a
  `Picture` (a label and the PNG bytes from `pbc.experiment.encode`) on the
  user turn, and `run(..., pictures=())`; the OpenAI client sends it as an
  image part. The replay format does not change: a recording holds no image.
  The pictures are regenerated by the build from the same `draw_` functions,
  the page shows them as figure cells, and the answer key computed at
  recording is kept in the lab module (judge configuration, never in a tool)
  so that a test detects a change of a source figure's physics, which then
  requires a re-recording.
- **Hidden truth never reachable.** The only tool is `answer` (AI6) or
  `explain` (AI7); it records the answer and returns an acknowledgement, no
  score and no truth. Choice answers are option numbers; numbers are bounded.
  One answer per question; a budget of one call per question.
- **Scoring from the transcript** (as `review_lab.verdicts`): accepted calls
  are read from the replayed transcript and scored against the recomputed
  key; the model's text is shown as recorded and never scored.
- **Controls and baselines.** AI6: the same model without the pictures (the
  same task, a system prompt that says they are not attached), and chance
  (uniform guessing, exact expected score). AI7: a curve-fit predictor of the
  plotted data (prediction without explanation: it cannot answer a
  counterfactual) and Rayleigh's dimensional analysis (an explanation without
  data: the form, not the constant).
- **Modules.** `pbc.agents.vision` (pictures, questions, the answer tool,
  scoring); `pbc.agents.multimodal_lab` (AI6) and
  `pbc.agents.explanation_lab` (AI7) with prompts, keys, and a live `main()`
  with `--record`; experiments
  `pbc.mechanics.experiments.multimodal_physics_reasoning` and
  `interpretable_physics_explanations`; unit tests for each.

## Recording

As in F66 and F81: no provider key is available, so the three runs (AI6 with
pictures, AI6 without, AI7 with the picture) are recorded by a Claude model
in a Claude Code session, a fresh sub-agent per run given only the system
prompt, the task, the tool specification, and (for the picture runs) the PNG
files the experiment wrote, read as images; the harness computes every
result. The fixtures' `model` field and the pages say so.

## Visual deliverables

Scientific figures only; the pictures shown to the model are existing
figures of other lessons, reused unchanged by their `draw_` functions.

Skills: pbc-scientific-visualization@a70b501

- AI6: the score of each question by kind for the run with pictures, the run
  without, and chance (a dot chart, told apart by marker and position).
- AI7: per question, the model's interval and value against the verified
  result (an interval plot), with the explanation tests in a table.
- Validation: the experiments' tests assert the recomputed keys and scores;
  the module's unit tests check the scaling test and the scoring.
- Fallback: alt text describing every figure; every number also in a table.

## Discoveries during the work

- **The dataset check follows imports transitively.** A module that imports
  a `pbc.data` reader makes every name derived from it data, and a figure of
  such names must name a dataset. AI6 is therefore split:
  `pbc.agents.multimodal_questions` (questions, prompts, the three simulated
  pictures, their key, the replay; no data) and `pbc.agents.multimodal_lab`
  (picture D, its part of the key, the full key, the live run). AI7 imports
  only the first. The check follows names, not scopes, so the readings figure
  of AI6 uses names of its own and covers the three numeric questions about
  the simulated plot; the question about the spectrum is in the table.
- **Recording.** Three runs on 2026-10-29, `claude-sonnet-5-5` sub-agents,
  each given only its system prompt, the task, the tool specification, and
  for the picture runs the PNG files the experiment's code wrote; every result
  computed by the harness and relayed. No run was discarded.
- **Results, reported as scored.** AI6: 11 of 11 with the pictures and 11 of
  11 without, at the reading tolerance fixed before the runs (a tenth); the
  run with the pictures is closer to the truth on all four numeric questions.
  The page states that the count does not separate reading from knowing on
  this question set; the tolerance is not changed after the runs, and an
  exercise shows the stricter tolerances. AI7: every prediction and every
  explanation passes; the curve fit misses the counterfactual, dimensional
  analysis leaves the velocity at four seconds undecided.
- **Architecture.** `docs/architecture.md` is a protected path and is not
  edited; the picture input of the harness is documented in
  `docs/authoring.md` ("Agent lessons") and `docs/project-map.md`.
